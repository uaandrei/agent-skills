# Project manifesto

Follow these mandatory rules on every task. They take precedence over all other project instructions.

1. **Never deploy to production.** If you detect that an action would trigger a production deployment or that one is already underway, stop immediately. Tell the user what you detected and what triggered or would trigger the deployment, then ask how to proceed.
2. **Ask when you are unsure how to proceed.** Tell the user what information or decision you need. Wait for their answer before making the decision or continuing the work that depends on it.

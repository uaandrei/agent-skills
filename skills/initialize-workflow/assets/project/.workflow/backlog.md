# Project backlog

Add or edit rows to track issues and features. Give each new entry the next available ID in the `B-001` format. Keep the ID when editing an entry and retain finished entries so their references still resolve. Order open entries by priority if useful.

Use **Issue** or **Feature** for the type. Start new entries as **Open**, use **In progress** for work underway, and mark completed work **Done**. Use **Closed** for withdrawn or declined items and record the reason in the notes. Link the work item in the notes when there is one. If a completed work item's directory is deleted, replace its link with the Git commit hash containing its final records. [Workflow instructions](../WORKFLOW.md)

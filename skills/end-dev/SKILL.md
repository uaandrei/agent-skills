# End dev session

1. If no dev session started with `start-dev` is active in this conversation, say so and change nothing.
2. Otherwise, follow the **End a dev session** section of the project's `WORKFLOW.md`: stop, record progress, propose learnings from the session as standards or workflow improvements, apply the ones the user accepts, and offer to commit the session records.
